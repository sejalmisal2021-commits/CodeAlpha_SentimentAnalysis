# CodeAlpha Sentiment Analysis Project

## Project Title
Sentiment Analysis using Python

## Description
This project analyzes the sentiment of a user's text input and classifies it as Positive, Negative, or Neutral using the TextBlob library.

## Technologies Used
- Python
- TextBlob

## Files
- sentiment_analysis.py : Python script for sentiment analysis

## How to Install
pip install textblob
python -m textblob.download_corpora

## How to Run
python sentiment_analysis.py

## Sample Input
I love this internship.

## Sample Output
Positive Sentiment 😊

## Features
- Takes user input as text
- Detects Positive, Negative, and Neutral sentiments
- Simple and easy-to-use command-line application
